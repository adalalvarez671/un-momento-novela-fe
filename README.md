# Un momento para ti — Novela de fe

Carpeta compartida con Muse. Cada episodio vive en `proyectos/<episodio>/`:

- `input/01.jpg … 06.jpg` — imagen inicial de cada clip (en orden).

Referencias de personajes en `personajes/`. Formato 9:16, 6 clips × 10 s, sin música (se agrega después).
